# 💰 Economic Calculator

A modern, interactive web app to calculate key financial and economic values — including **asset depreciation**, **loan repayments**, and **Net Present Value (NPV / VAN)** — built with **React + TypeScript** for speed and clarity.

## 🚀 Live Demo
👉 [Try it here](https://koussaiicode.vercel.app/)  
*(Deployed on Vercel — fast, responsive, and colorful!)*

---

## ✨ Features

- 📉 **Depreciation Calculator** — Supports Linear, Declining Balance, and Sum-of-Years-Digits methods.  
- 💵 **Loan Calculator** — Compute monthly payments, total interest, and amortization schedules.  
- 📊 **VAN (NPV) Tool** — Evaluate investment projects with detailed step-by-step results.  
- 🧮 Clean and intuitive UI for quick calculations.  
- 🌈 Colorful, modern design made with Tailwind CSS.  
- ⚡ Fast performance powered by React + Vite.

---

## 🛠️ Tech Stack

- **React** + **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Framer Motion** (for smooth animations)
- **Lucide Icons**
- **Deployed on Vercel**
